# Bug Report: 文件上传接口 `POST /cms/file/0` 全部返回 500 服务器端异常

**Bug ID**: BUG-FILE-UPLOAD-500-001  
**标题**: `POST /cms/file/0` 上传任何文件类型均返回 `error_code: 999` 服务器端异常  
**模块**: 文件管理 / 文件上传  
**严重级别**: 高  
**优先级**: P0  
**状态**: ✅ 已修复  
**发现日期**: 2026-06-18  
**修复日期**: 2026-06-19  
**提交人**: 测试团队 4号

---

## 一、问题概述

4号文件测试中，所有涉及文件上传的测试用例均失败。`POST /cms/file/0` 接口无论上传什么文件类型（png、jpg、pdf、xlsx、mp4），均返回：

```json
{"error_code": 999, "msg": "服务器端异常", "request_url": "POST /cms/file/0"}
```

影响范围极广，导致 TC-FILE-001 到 TC-FILE-006（6个正常上传）、TC-FILE-023（上传下载完整性）、TC-FILE-025（去重上传）、TC-FILE-027/028（文件夹上传移动）、TC-FILE-029（文件复制）共 **10 个用例**全部失败。

## 七、根因分析（已确认 ✅）

### DEBUG 模式下的真实异常堆栈

在 DEBUG 模式启动服务器后，上传文件抛出的真实异常：

```
sqlalchemy.exc.DataError: (pymysql.err.DataError) (1366, 
"Incorrect integer value: 'UrlFromEnum.LOCAL' for column 'from' at row 1")

SQL: INSERT INTO file (create_time, update_time, delete_time, parent_id, 
  uuid_name, name, path, extension, `from`, size, md5) VALUES (...)

参数中 `from` 列传入了字符串 `'UrlFromEnum.LOCAL'` 而非整数值 `1`
```

### 根因代码

`app/models/file.py` 第22行：

```python
# ❌ 错误：传入了枚举对象本身，SQLAlchemy将其序列化为字符串
_from = Column('from', SmallInteger, default=UrlFromEnum.LOCAL, ...)

# ✅ 正确：应传入枚举的值（整数）
_from = Column('from', SmallInteger, default=UrlFromEnum.LOCAL.value, ...)
```

### 同类代码对比

`app/models/image.py` 第18行使用的是正确写法：

```python
_from = Column('from', SmallInteger, default=UrlFromEnum.LOCAL.value, ...)
```

### 异常传播链路

```
POST /cms/file/0
  → LocalUploader.upload()
    → File.create() 写入数据库
      → SQLAlchemy 将 UrlFromEnum.LOCAL 序列化为字符串
        → MySQL SMALLINT 列拒绝接收字符串
          → pymysql.err.DataError
            → 全局异常处理器 handle_error(e)
              → DEBUG=False → return ServerError()
                → {"error_code": 999, "msg": "服务器端异常"}
```

---

## 八、修复方案

### 修复内容

修改 `app/models/file.py` 第22行，将 `default=UrlFromEnum.LOCAL` 改为 `default=UrlFromEnum.LOCAL.value`：

```python
# 修改前
_from = Column('from', SmallInteger, default=UrlFromEnum.LOCAL, comment='来源: 1 本地，2 公网')

# 修改后
_from = Column('from', SmallInteger, default=UrlFromEnum.LOCAL.value, comment='来源: 1 本地，2 公网')
```

### 改进建议
- 在 `app/api/cms/file.py` 的上传处理中增加 try-except，打印具体异常堆栈而非依赖全局 999
- 为文件上传接口增加数据库写入的健康检查
- 补充上传失败的详细错误码，替代泛化的"服务器端异常"

## 十二、结论

该问题属于 **P0 级阻断性缺陷**，根因是 `app/models/file.py` 中 `_from` 列的 `default` 参数误传了 `UrlFromEnum.LOCAL` 枚举对象（而非其 `.value` 值 `1`），导致 SQLAlchemy 向 MySQL `SMALLINT` 列插入字符串 `'UrlFromEnum.LOCAL'`，触发 `DataError`。
