# Bug Report: 无 Token 上传文件返回 500 而非 4xx 认证错误

**Bug ID**: BUG-FILE-AUTH-500-001  
**标题**: `POST /cms/file/0` 无 Token 上传文件时返回 500 服务器端异常，而非 401 未认证  
**模块**: 文件管理 / 认证鉴权  
**严重级别**: 中  
**优先级**: P1  
**状态**: ✅ 已修复  
**发现日期**: 2026-06-18  
**修复日期**: 2026-06-19  
**验证日期**: 2026-06-19  
**提交人**: 测试团队 4号

---

## 一、问题概述

TC-FILE-010 测试"无 Token 上传文件"场景，期望返回 4xx（如 401 未认证），但实际返回了 500：

```json
{"error_code": 999, "msg": "服务器端异常", "request_url": "POST /cms/file/0"}
```

---

## 二、实际测试结果

```
AssertionError: [TC-FILE-010] 期望 4xx, 实际 500
```

---

## 修复确认（2026-06-19）

**两项修复配合生效：**

1. **DB 层修复**：`app/models/file.py:22` 的 `_from` 列 default 从 `UrlFromEnum.LOCAL` 改为 `UrlFromEnum.LOCAL.value`
2. **鉴权层修复**：恢复 `app/api/cms/file.py` 中 `upload_file()` 和 `move_files()` 的 `@auth.group_required` 装饰器

**验证结果**：TC-FILE-010 PASSED，无 Token 上传正确返回认证错误。

**关闭。**
