# Bug Report: 创建订单缺少幂等控制

**Bug ID**: BUG-ORDER-IDEMPOTENCY-001  
**模块**: 订单创建  
**严重级别**: 高  
**优先级**: P0  
**状态**: 已定位 / 未修复  
**发现日期**: 2026-06-19  
**提交人**: 测试团队3号

## 问题概述

相同用户、相同商品和数量的请求重复提交时，系统每次都生成新订单。顺序提交2次生成订单29、30；并发提交5次生成5个不同订单。

## 影响

- 网络重试可能产生重复订单。
- 用户可能被重复引导支付。
- 并发场景下可能造成库存和账务风险。

## 预期结果

客户端携带幂等键后，相同业务请求只能生成一笔有效订单；重复请求应返回首次结果。

## 根因分析

`POST /v1/order` 和 `OrderService.palce()` 未接收或校验幂等键，也没有请求指纹、唯一约束或防重记录。每次调用都会生成新订单号并写库。

## 修复建议

1. 要求客户端提交唯一幂等键。
2. 建立“用户ID+幂等键”唯一约束。
3. 在同一事务内查询或创建订单。
4. 对并发重复请求返回首次订单结果。
