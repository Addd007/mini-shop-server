# Bug Report: 超大文件上传测试 `ApiClient.request()` 不支持 `timeout` 关键字参数

**Bug ID**: BUG-FILE-OVERSIZED-TIMEOUT-001  
**标题**: `test_upload_oversized_rejected` 调用 `auth_client.request(..., timeout=120)` 报 TypeError  
**模块**: 文件管理 / 测试代码  
**严重级别**: 低  
**优先级**: P2  
**状态**: ✅ 已修复  
**发现日期**: 2026-06-18  
**修复日期**: 2026-06-19  
**提交人**: 测试团队 4号

---

## 一、问题概述

TC-FILE-026 调用 `auth_client.request("POST", "/cms/file/0", files={...}, timeout=120)`，抛出 `TypeError: request() got an unexpected keyword argument 'timeout'`。`ApiClient.request()` 方法签名不支持 `timeout` 关键字参数。

---

## 二、影响范围

### 受影响功能
- 超大文件上传边界测试

### 受影响接口
- `POST /cms/file/0`

### 业务影响
- TC-FILE-026 无法执行（测试代码 bug，非服务问题）

---

## 三、复现步骤

查看 `test_upload_oversized_rejected` 函数：

```python
resp = auth_client.request(
    "POST", "/cms/file/0",
    files={"file": ("big_file.zip", fh)},
    timeout=120,  # ← ApiClient.request() 不接受此参数
)
```

---

## 四、实际结果

`TypeError: request() got an unexpected keyword argument 'timeout'`

---

## 五、预期结果

`ApiClient.request()` 应支持 `timeout` 参数透传至 `requests.Session.request()`。

---

## 六、根因分析

`ApiClient.request()` 方法签名中未包含 `**kwargs` 或显式的 `timeout` 参数，无法透传。

---

## 七、修复方案

使用独立的 `ApiClient` 实例携带 120 秒超时，而非直接传 `timeout` 参数：

```python
big_client = ApiClient(base_url=auth_client.base_url, timeout=120, token=auth_client.token)
resp = big_client.request("POST", "/cms/file/0", files={"file": ("big_file.zip", fh)})
```
