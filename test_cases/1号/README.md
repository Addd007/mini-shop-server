# 1号测试用例目录

> 角色：核心功能测试
> 适用范围：mini-shop-server 接口测试与回归测试
> 测试基线：`zerd_test.sql`

本目录按模块拆分 1 号负责的测试用例，便于日常执行、回归和后续自动化维护。

## 文件说明

| 文件 | 模块 | 内容 |
|---|---|---|
| `auth.md` | 登录与鉴权 | 登录、Token、用户信息、异常登录 |
| `user.md` | 用户与权限 | 当前用户信息、权限边界、停用账号 |
| `product.md` | 商品与分类 | 商品列表、详情、分类、属性、图片 |
| `order.md` | 订单 | 订单创建、订单状态、快照、金额 |
| `file.md` | 文件与静态资源 | 文件目录、下载、图片访问、上传前置 |
| `notice_article.md` | 通知与文章 | 通知列表、公告、文章列表、文章详情 |
| `config_dict.md` | 配置与字典 | 站点配置、上传配置、字典查询 |
| `log.md` | 日志 | 登录日志、操作日志 |

## 测试数据约定

- 用户账号：`admin / admin123456`、`alice / alice123456`、`bob / bob123456`
- 订单样例：`202606090001`、`202606090002`
- 商品样例：`iPhone 15`、`ThinkPad X1`、`小米充电宝`
- 文件样例：`banner-1.jpg`、`product-1-main.jpg`、`resume.pdf`

## 使用方式

每个文件都是独立的模块测试用例清单，执行时可直接按表格逐条打勾并记录实际结果。
