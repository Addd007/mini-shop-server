**标题**: `GET /cms/log/error/list` 异常日志查询接口返回 404，路由未注册  
**模块**: 日志审计 / 异常日志  
**严重级别**: 中  
**优先级**: P1  
**状态**: ✅ 已修复  
**发现日期**: 2026-06-18  
**修复日期**: 2026-06-19  
**验证日期**: 2026-06-19  
**提交人**: 测试团队 4号

---

## 一、最新测试结果（2026-06-19）

```
AssertionError: [TC-LOG-009] 期望 200, 实际 404
```

TC-LOG-009 仍然 FAILED，确认是服务端路由缺失问题（非测试代码问题）。

---

## 二、复现

```
GET /cms/log/error/list
Authorization: Bearer <admin_token>
→ 404 Not Found
```

---

## 三、根因与修复

**根因**：`app/config/setting.py` 的 `ALL_RP_API_LIST` 中遗漏了 `'cms-error_log'` 模块，导致该 Blueprint 未注册。

**修复**：在 `ALL_RP_API_LIST` 中添加 `'cms-error_log'`：
```python
['cms-admin', ..., 'cms-login_log', 'cms-error_log'] + \
```

**验证**：TC-LOG-009 ✅ PASSED（2026-06-19）
