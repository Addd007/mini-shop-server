# Bug Report: `POST /cms/file/new` 返回成功但文件夹未实际创建

**Bug ID**: BUG-FILE-NEW-FOLDER-SILENT-FAIL-001  
**标题**: `POST /cms/file/new` 返回 `error_code: 0` 但文件夹未出现在文件列表中  
**模块**: 文件管理 / 新建文件夹  
**严重级别**: 高  
**优先级**: P0  
**状态**: 🔴 已确认（服务端 Bug）  
**发现日期**: 2026-06-19  
**提交人**: 测试团队 4号

---

## 一、问题概述

`POST /cms/file/new` 接口创建文件夹时，返回 `{"error_code": 0, "msg": "成功"}` 但新创建的文件夹并未出现在后续 `GET /cms/file/list` 的文件列表中。

无论使用何种文件夹名称（短名称、长名称、中文、英文），问题均可稳定复现：

| 文件夹名 | 长度 | 创建状态 | 列表中是否找到 |
|----------|------|---------|---------------|
| `test123` | 7 | 200 OK | ❌ 否 |
| `short_test` | 10 | 200 OK | ❌ 否 |
| `4号测试文件夹_1234` | 12 | 200 OK | ❌ 否 |
| `a` × 50 | 50 | 200 OK | ❌ 否 |

## 三、复现步骤

```python
# 1. 获取 token
r = requests.post('http://127.0.0.1:5000/v1/token',
    json={'account': 'super', 'secret': '123456', 'type': 100})
token = r.json()['data']['token']

# 2. 创建文件夹
s = requests.Session()
s.auth = HTTPBasicAuth(token, '132')
r2 = s.post('http://127.0.0.1:5000/cms/file/new',
    params={'parent_id': '0', 'filename': 'test123'})
# → {"data": null, "error_code": 0, "msg": "成功"}

# 3. 查询文件列表
r3 = s.get('http://127.0.0.1:5000/cms/file/list',
    params={'parent_id': '0', 'count': 100})
# → 列表中不包含 'test123'
```

---

## 四、根因假设

可能的根因：

1. **数据库写入失败但未抛出异常** — DAO 层 insert 返回成功但数据未 commit
2. **`data: null` 响应** — 创建操作未返回创建结果，可能表示空操作
3. **参数校验未生效** — 某些参数（filename 长度/字符限制）导致静默跳过
4. **事务回滚** — 创建成功但事务未提交，导致数据不可见
