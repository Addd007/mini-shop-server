# Bug Report: 已支付订单无法发货

**Bug ID**: BUG-ORDER-STATE-001  
**模块**: 订单状态流转  
**严重级别**: 高  
**优先级**: P0  
**状态**: 已定位 / 未修复  
**发现日期**: 2026-06-19  
**提交人**: 测试团队3号

## 问题概述

将订单状态设置为2（已支付）后调用 `PUT /cms/order/delivery?order_id=1`，接口仍返回403“订单未支付”，订单无法进入已发货状态。

## 实际结果

```json
{"error_code":8002,"msg":"订单未支付，或已经更新过订单了"}
```

## 预期结果

已支付订单应发货成功，状态由2变为3。

## 根因分析

`app/service/order.py` 中将数据库整数与枚举对象直接比较：

```python
if order.order_status != OrderStatusEnum.PAID:
```

应与 `OrderStatusEnum.PAID.value` 比较；赋值时也应写入 `OrderStatusEnum.DELIVERED.value`。
